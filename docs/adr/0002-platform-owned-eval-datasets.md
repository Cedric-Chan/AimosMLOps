# 评测集由平台集中持有（owner = 平台团队）

Status: accepted (2026-09-22)

所有场景（PH / TH / MY 及后续）的评测集 owner 为平台团队（AimosTeam）；业务团队对评测集**只读 + 提交用例**，不持有资产。业务方的参与形式是三交付物——用例、通过标准、签署人——其中「通过标准」的业务判据（审核标准 / 抽取标准 / 结论对错真值）由业务方签署拥有，准确率等性能目标由工程在成本约束下校准（业务不给准确率定目标）。

## Considered Options

- **谁的业务谁持有评测集**：被否——评测覆盖率与回归拦截数是平台团队的产出所有权指标（有人对数字负责的位置砍起来要付代价）；资产散给业务团队后，覆盖率分母不再受平台控制，运营也会随业务方精力衰减（表格时代的评测集正是这样烂掉的）。
- **混合持有**：被否——首期三场景中 PH 的服务本就归属平台团队（AimosTeam），TH/MY 新场景在上线前没有现成的资产持有方；先集中、出现真实的多团队自治需求再谈。

## Consequences

- 用例运营（失败→用例的采纳闸门、去重、保鲜）第一季度由平台集中承担；之后写进**服务接入协议**：新 LLM 服务上线必须自带 ≥N 条用例 + 通过标准 + 签署人。
- 可见性默认：团队内可写、报告层公开（报告只含聚合与脱敏样例）；跨团队共享需显式授权，暂不预建机制。
- 评测集存判定结论与抽取字段，不存报文正文（PII 红线）；业务驳回自动回流为标注与候选用例。
